public function featured($filters = [])
{
    $sql = "SELECT p.*, c.name AS category_name, s.shop_name
            FROM products p
            JOIN categories c ON c.id = p.category_id
            JOIN sellers s ON s.id = p.seller_id
            WHERE p.is_available = 1";
    $params = [];

    if (!empty($filters['category'])) {
        $sql .= " AND p.category_id = ?";
        $params[] = (int) $filters['category'];
    }

    if (!empty($filters['q'])) {
        $sql .= " AND (p.name LIKE ? OR p.description LIKE ? OR s.shop_name LIKE ?)";
        $term = '%' . $filters['q'] . '%';
        $params[] = $term;
        $params[] = $term;
        $params[] = $term;
    }

    $sql .= " ORDER BY p.created_at DESC";
    return $this->db->query($sql, $params);
}

Code Explanation

featured() fetches only available products and joins categories and sellers, so product cards can show category and shop information.

The search filter checks product name, product description, and seller shop name.

The category filter limits results to a selected category using category_id.

Fallback images are handled by product_image() in customer/app/core/functions.php, preventing broken images on the home page.

public function add($id = null)
{
    $product = $this->model('Product')->find((int) $id);
    if (!$product || !(int) $product['is_available']) {
        flash('error', 'This product is not available.');
        redirect('');
    }

    if ((int) $product['stock_quantity'] < 1) {
        flash('error', 'This product is currently out of stock.');
        redirect('');
    }

    $_SESSION['cart'] = $_SESSION['cart'] ?? [];
    $currentQty = (int) ($_SESSION['cart'][$product['id']] ?? 0);
    $_SESSION['cart'][$product['id']] = min($currentQty + 1, (int) $product['stock_quantity']);

    flash('success', 'Product added to cart.');
    redirect('cart');
}

public function allForUser($userId)
{
    $orders = $this->db->query(
        "SELECT * FROM orders WHERE user_id = ? ORDER BY created_at DESC",
        [(int) $userId]
    );

    foreach ($orders as &$order) {
        $order['items'] = $this->items($order['id'], $userId);
    }

    return $orders;
}

public function items($orderId, $userId)
{
    return $this->db->query(
        "SELECT oi.*, p.name, p.primary_image, s.shop_name
         FROM order_items oi
         JOIN orders o ON o.id = oi.order_id
         JOIN products p ON p.id = oi.product_id
         JOIN sellers s ON s.id = oi.seller_id
         WHERE oi.order_id = ? AND o.user_id = ?
         ORDER BY oi.id",
        [(int) $orderId, (int) $userId]
    );
}

Code Explanation

Order history is restricted to logged-in customers only.

allForUser() fetches only the orders belonging to the current customer.

Each order is expanded with its related order_items using the items() method.

The item query checks both order_id and user_id, preventing one customer from viewing another customer's order items.

Feature 3.1.10: Fallback Images and Session Storage

The system shows default images when real product or profile images are missing. The customer app also stores PHP session files inside the project storage folder, which avoids permission problems with the default XAMPP temporary session folder.

Relevant Source Code

File: customer/app/core/functions.php

function product_image($path)
{
    $path = trim((string) $path);

    if ($path !== '') {
        $customerFile = dirname(__DIR__, 2) . '/public/' . $path;
        $sellerFile = dirname(__DIR__, 3) . '/seller/' . $path;

        if (is_file($customerFile)) {
            return url($path);
        }

        if (is_file($sellerFile)) {
            return project_url('seller/' . $path);
        }

        if (preg_match('#^https?://#', $path)) {
            return $path;
        }
    }

    return url('assets/images/default-product.svg');
}

File: customer/public/index.php

$sessionPath = dirname(__DIR__) . '/storage/sessions';
if (!is_dir($sessionPath)) {
    mkdir($sessionPath, 0777, true);
}
session_save_path($sessionPath);
session_start();

Code Explanation

product_image() first checks whether a real image exists inside the customer public folder.

If not found there, it checks the seller folder, which allows customer pages to display product images uploaded from the seller side.

If no real image is found, the app uses assets/images/default-product.svg.

session_save_path() stores session files in customer/storage/sessions, which supports login, cart, and flash messages without depending on C:\xampp\tmp permissions.
